**数据**：新能源汽车动力电池遥测数据（6231 行 × 24 列，约 35 小时，采样 10 秒）

---

## 二、异常值处理

### 检测方法
采用 **物理合理性边界 + 3σ 统计离群** 双方法（IQR 方法对时间序列遥测数据会产生大量误报，故未采用）。

### 检测结果

| 字段 | 物理越界 | 3σ 统计离群 | 说明 |
|------|----------|-------------|------|
| speed | 0 | 104 | 高速行驶（>75 km/h）段 |
| summileage | 0 | 0 | 正常 |
| sumvoltage | 0 | 0 | 正常 |
| sumcurrent | 0 | 181 | 大电流充/放电段 |
| soc | 0 | 0 | 正常 |
| insulationresistance | 0 | 78 | 充电瞬间绝缘电阻升高 |
| max_cell_volt | 0 | 0 | 正常 |
| min_cell_volt | 0 | 0 | 正常 |
| max_temp | 0 | 299 | 温度波动 |
| min_temp | 0 | 250 | 温度波动 |
| **合计** | **0** | **912** | — |

### 处理策略
- **物理越界：0 条** —— 数据均在工程合理范围内，无需剔除。
- **3σ 统计离群：912 条** —— 这些是**真实工作状态**（高速行驶、大功率充放电、温度变化），**非错误数据，不做删除/修改**，仅在数据表中用 `is_outlier` 列标记（1=离群），供后续分析参考。

## 三、特征工程（衍生特征）

| 衍生特征 | 公式/含义 | 用途 |
|----------|-----------|------|
| `volt_diff` | max_cell_volt − min_cell_volt | 电池压差（一致性/健康核心指标）|
| `temp_diff` | max_temp − min_temp | 温差（热管理指标）|
| `avg_cell_volt` | (max+min_cell_volt)/2 | 平均单体电压 |
| `is_charging` | chargestatus==2 时为 1 | 充电状态二值化 |
| `power` | sumvoltage × sumcurrent / 1000 | 电池功率 (kW)，正=充电/负=放电 |

### 关键统计洞察

1. **车速 `speed`**：中位数 0，说明车辆大部分时间处于静止（充电/停车），行驶是少数时段；最大 100.7 km/h。

2. **累计里程 `summileage`**：25%分位=中位数=75%分位=40091，说明约 50% 时间车辆停在 40091 km 处（数据中段静止），总里程 39938→40152（214 km）。

3. **SOC**：均值 58%，中位数 64%，覆盖 7%~100%，说明数据包含一次完整的深度放电+充电循环。

4. **总电流 `sumcurrent`**：中位数 -8.8 A（微放电），25%分位 -9.2，75%分位 0.8，跨度 -113.1~240.3 A，反映行车放电和充电两种工况。

5. **压差 `volt_diff`**：均值 0.0097 V，最大 0.096 V。压差整体很小（电池一致性好），最大压差 96 mV 出现在低 SOC 深放阶段。

6. **温度**：max_temp 集中在 10℃（冬季），max~min 温差仅 2℃ 以内，热管理良好。
