# 数据说明（data/）

## 原始数据不入库

本项目使用的原始文件是 **SHEVDC 平台导出的单车运行记录**（`SHEVDC_OV6N7709.csv`，约 640 KB），包含车辆运行与充电的逐条记录。

**不提交到仓库的原因**：

1. 数据来自平台导出，可能涉及车辆/企业信息，公开仓库不适合存放；
2. 复盘者只需按本说明放入同名文件即可完整复现所有图表与结论。

## 如何准备数据

1. 把文件放到 `data/raw/SHEVDC_OV6N7709.csv`（`data/raw/` 已在 `.gitignore` 中忽略）；
2. 保持 UTF-8 编码、列名不变；
3. 打开 notebook 直接运行——代码会自动在 `data/raw/` 和 `../data/raw/` 两处找文件。

## 字段说明（GB/T 32960 格式）

| 字段 | 含义 | 单位 |
|------|------|------|
| `time` | 上报时间（10 秒一条） | — |
| `vehiclestatus` | 车辆状态：1=启动，2=熄火 | — |
| `chargestatus` | 充电状态：1=停车充电，2=行驶充电，3=未充电，4=充电完成 | — |
| `speed` | 车速 | km/h |
| `sumvoltage` | 总电压 | V |
| `sumcurrent` | 总电流（正=放电，负=充电） | A |
| `soc` | 剩余电量 | % |
| `summileage` | 累计里程 | km |
| `max_cell_volt` / `min_cell_volt` | 最高 / 最低单体电压 | V |
| `max_temp` / `min_temp` | 最高 / 最低温度 | °C |
| `insulationresistance` | 绝缘电阻上报值（单位口径待确认） | — |

## 数据规模

- 6,231 行 × 24 列
- 时间范围：2019-01-10 01:12 — 2019-01-11 12:16（35.1 小时）
- 覆盖率：49.3%（缺口为车辆未上线时段）
