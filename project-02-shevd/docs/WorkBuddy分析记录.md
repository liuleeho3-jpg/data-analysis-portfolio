| 物理越界（真错误） | 0 条 |
| 3σ 统计离群（真实工况） | 912 条 |

## 复核备注（2026-11-05 复核）

把原始 CSV 重新读入并核对后，有三点需要说明：

1. **`"ffill"` 污染确认属实**：`summileage` 中恰好 4,263 行为字符串 `"ffill"`，有效数值 1,968 行；4 处里程跳变（+3、+17、+2、+3 km）也完全对上。**原记录的这一发现是准确的**，也是本次分析最有价值的清洗点。
2. **充电状态口径**：原记录开头把 `chargestatus=4` 解读为"充电中"，后文未再下结论。按 GB/T 32960 应为：**1=停车充电、2=行驶充电（能量回收）、3=未充电、4=充电完成**。数据也支持这一映射——`chargestatus=4` 的 54 行全部是 SOC=100%、车速 0、电流≈0 的结束状态。
3. **电流正负号**：原记录一处写"正=充/负=放"。按 GB/T 32960 与数据实际表现应为 **正=放电、负=充电**（充电段的 `sumcurrent` 为负、SOC 上升）。这对 `power` 的符号有影响，取绝对值不影响能量总量结论。
