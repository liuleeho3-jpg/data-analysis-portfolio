## 卡点排查表

| 现象 | 原因 | 解决 |
|------|------|------|
| `ModuleNotFoundError: No module named 'pandas'` | 没激活 `da` 环境，或没装 | `conda activate da`，再 `pip install pandas` |
| Jupyter 里 import 报错，但命令行正常 | notebook 用的 kernel 不是 `da` | `conda activate da` 后 `python -m ipykernel install --user --name da`，在 Jupyter 里切换 kernel |
| `FileNotFoundError: data/titanic.csv` | 相对路径不对 | notebook 在 `notebooks/` 下，应写 `../data/titanic.csv` |
| `UnicodeDecodeError` | 文件编码不是 UTF-8 | `pd.read_csv(path, encoding="utf-8")`，不行换 `"gbk"` |
| `git push` 反复要密码 / 403 | GitHub 停用密码认证 | 用 Personal Access Token 当密码；或装 GitHub Desktop |
| Kaggle 下载要登录 | 需要账号 | 用备用 raw 链接（Day 2 已给） |
| pip 下载超时 | 网络 | 命令末尾加 `-i https://pypi.tuna.tsinghua.edu.cn/simple` |
| Jupyter 没自动打开浏览器 | 端口/默认浏览器问题 | 复制终端里的 `http://localhost:8888/?token=...` 手动打开 |
| 图表中文变方块 | matplotlib 默认字体无中文 | `plt.rcParams["font.sans-serif"] = ["Microsoft YaHei"]` |
